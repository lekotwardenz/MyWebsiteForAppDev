# Review: MyWebsiteForAppDev

**Reviewer:** Cando, Johanne Froilan T.
**Repository:** https://github.com/lekotwardenz/MyWebsiteForAppDev

---

## Project Structure Rating: 9/10

The project has the usual Blazor layout, with Components, wwwroot, Properties, Program.cs, and the appsettings files where they should be. The folder names are clear and easy to follow, and the 7 commits show the project was built step by step. The only thing holding it back is that the bin, obj, and node_modules folders were committed, so adding them to the .gitignore would make the repo cleaner.

---

## Front-End Rating: 10/10

This is a good website, and I really liked the design and how it was done. The look feels clean and well put together, so it was nice to go through. It feels like a project that was made with care.

---

**Overall:** Nice work! Cleaning up the committed build folders is the one thing I would fix.
